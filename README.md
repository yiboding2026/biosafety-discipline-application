## 核心判断（基于公开权威资料）

1. **我国新设一级学科实行"先试点、后编入目录"机制**。依据《研究生教育学科专业目录管理办法》（2022年）和《交叉学科设置与管理办法（试行）》（学位〔2021〕21号），新增一级学科须先经试点设置（交叉学科试点代码以"99"开头），试点单位不少于3所、毕业生不少于3届后方可申请编入目录。
2. **生物安全已进入国家法律与国家安全体系**。《中华人民共和国生物安全法》（2020年10月17日通过，2021年4月15日施行）第三条明确"生物安全是国家安全的重要组成部分"，第六十九条要求加强生物领域人才培养、推动学科建设。
3. **国内已有实质性学科布局但尚无一枚"生物安全"一级学科**。兰州大学建有全国首个"生物安全"交叉学科学术学位博士点；中山大学于2025/2026年度自主审核中获批"生物安全"交叉学科博士点及硕士点，并于**2026年5月将公共卫生学院（深圳）更名为生物安全学院（全国首个以生物安全命名的学院）**；多所高校在植物保护、兽医学、公共卫生等一级学科下设生物安全方向。
4. **最现实的路径不是一步到位申报一级学科**，而是：先以目录外二级学科/交叉学科（含试点交叉学科）方式建设 → 形成多校布局与毕业生规模 → 再推动编入目录。国家安全学从研究方向到一级学科用了约6年（2015年设立二级学科方向、2018—2019年试点、2020年12月设一级学科、2021年10月首批学位授权点）。
5. **学科边界论证是申报成败的第一道关**：必须系统回答与国家安全学、安全科学与工程、公共卫生与预防医学、兽医学/植物保护、生物学/生物工程等6个相邻一级学科的区别（详见 07 号文档）。
