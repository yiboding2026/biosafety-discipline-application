# 二、申报要求与支撑材料

> 说明：本章分两层——（A）设置"生物安全"**一级学科/试点交叉学科**的论证要求；（B）在已有（或未来新设）一级学科下申请**学位授权点**的审核要求。两者适用不同文件，勿混淆。

## A. 一级学科（试点交叉学科）设置的论证要求

### A.1 论证报告编写（学位〔2021〕21号第六条）

自主审核单位须"按提纲编写论证报告"（国务院学位办发布《新增交叉学科论证报告编写参考提纲》），论证报告核心要素围绕第五条规定展开：

| 论证维度 | 需回答的问题 | 支撑证据类型 |
|---|---|---|
| 研究对象与科学问题 | 什么是生物安全学科独有的研究对象？哪些科学问题必须多学科交叉才能解决？ | 学科内涵界定、与生物学/兽医学/公共卫生/安全科学与工程/国家安全学的边界分析 |
| 学科独立性 | 能否形成相对独立的理论、知识和方法体系？ | 已有理论体系梳理、国内外学术共同体（学会、期刊、会议）证据 |
| 社会需求 | 人才需求规模多大？是否迫切且稳定？ | 法律法规要求、行业主管部门需求文件、岗位与机构数据、用人单位调研 |
| 师资队伍 | 是否有结构合理的高水平教师队伍？ | 专任教师队伍规模、职称/学位/年龄结构、学科带头人学术地位 |
| 学科基础 | 相关学科是否扎实？ | 依托的博士点（涉及3个及以上具博士学位授权的一级学科是校内自设交叉学科的通行要求）、科研平台（国家重点实验室、P3实验室等） |
| 培养体系 | 是否基本形成研究生培养体系？ | 培养方案、课程体系、教材、已培养研究生情况 |

### A.2 程序性支撑材料

按学位〔2021〕21号第六条，须留痕的材料包括：

1. 主责院系书面申请；
2. 学位授权点管理部门初审意见；
3. 征求相关学位授权点意见的记录；
4. 论证报告（按参考提纲）；
5. 国内外同行专家论证意见（专家名单、意见原件）；
6. 校内公示证明；
7. 校学位评定委员会审议决议；
8. 党委常委会会议研究决定；
9. 经省级学位委员会报国务院学位委员会的正式文件。

## B. 学位授权点申请的审核要求（周期性授权审核）

### B.1 申请基本条件框架（《新增博士硕士学位授权审核申请基本条件》，2024年发布）

按**一级学科/专业学位类别分别制定**，通行框架包括：

| 模块 | 典型指标（以公开文件中学术学位点为例，具体以当年度文件为准） |
|---|---|
| 二级学科基础 | 至少2—3个稳定的主干二级学科，其中体现单位特色 |
| 学科队伍 | 专任教师规模（常见底线20—25人）、职称结构、博士学位比例、学缘结构、年龄结构；每个二级学科1名带头人+2名学术骨干 |
| 人才培养 | 硕士点申博点一般要求完整培养过若干届硕士生；课程门数；培养质量（论文抽检、就业） |
| 科学研究 | 近5年师均科研经费、国家级/省部级项目数、省部级以上科研奖励 |
| 学术交流 | 主办/承办学术会议次数、研究生参会比例 |
| 支撑条件 | 实验室/平台（省部级以上重点实验室等）、图书文献、奖助体系覆盖率 |
| 负面清单 | 近3年存在师德师风问题及学术不端行为并造成严重社会影响的学科不得申请 |

### B.2 申报材料清单（2024年周期性审核口径）

据《新增博士硕士学位授权审核工作总体要求》（教育部官网2024年发布）及各省通知：

- 《申请博士学位授权一级学科点简况表》/《申请硕士学位授权一级学科点简况表》/《申请博士硕士专业学位授权点简况表》；
- 《现有学位授权点骨干教师基本情况汇总表》；
- 新增学位授予单位另需：《新增博士硕士学位授予单位申请报告》（正文3000字以内）与《申请新增博士硕士学位授予单位简况表》；
- 校内环节：校学位评定委员会评议（2/3以上委员同意）及会议纪要、排序表决结果、校内公示证明（一般不少于3天）；
- 佐证材料（备查）：教师、项目、经费、奖励、平台等证明文件。**对核查中不能提供证明材料的，按材料作假处理**。

### B.3 省级环节要求

- 省级学位委员会制订**申报指南**：结合《急需学科专业引导发展清单》，优先支持国家发展重点领域、本地区空白或急需领域；对布点较多、就业不佳的学科限制新增；可提出附加条件（不得降低国家基本条件）；
- 申请材料在省级教育部门官网公示**不少于5个工作日**；
- 省级专家组评议：每组不少于9人（含学科评议组成员或教指委委员），2/3（含）以上同意为通过；
- 省级审议表决、排序、公示不少于5个工作日后报国务院学位委员会。

### B.4 国家层面环节

- 博士点：两轮评议——第一轮网络评议，第二轮学科评议组/教指委复审，2/3（含）以上同意通过；
- 硕士点：按10%比例核查（上轮核查不合格比例较高地区提至30%）；
- 拟新增名单公示不少于10个工作日后由国务院学位委员会审议批准。
- 2024年审核结果（2024年7月31日公示）：新增831个博士学位授权点（一级学科480个、专业学位351个）、1924个硕士学位授权点（一级学科358个、专业学位1566个）、6个学位授权自主审核单位。

## C. 生物安全申报的特殊考量

1. **归口沟通**：若按国家安全相关口径申报，参照2024年总体要求中"申请国家安全学等一级学科授权点需经有关部门同意"的先例，需提前取得行业主管部门（如国家卫生健康委、农业农村部、海关总署、国家疾控局及国家安全相关部门）支持文件。
2. **平台证据**：高等级病原微生物实验室（P3/P4）、菌（毒）种保藏机构等国家战略资源平台是关键支撑条件（《生物安全法》第六十八条），申报单位应梳理可依托平台清单。
3. **方向凝练**：需论证与国家安全学（下设国家安全思想与理论、国家安全战略、国家安全治理、国家安全技术4个二级学科）、生物学、植物保护、兽医学、公共卫生与预防医学、安全科学与工程等现有一级学科的清晰边界。
