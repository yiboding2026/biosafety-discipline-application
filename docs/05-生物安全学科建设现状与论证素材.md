# 五、生物安全学科建设现状与论证素材

## 5.1 法律与政策依据

### 《中华人民共和国生物安全法》
- 2020年10月17日第十三届全国人大常委会第二十二次会议通过，2021年4月15日施行。
- **第三条**：生物安全是国家安全的重要组成部分。维护生物安全应当贯彻总体国家安全观，统筹发展和安全，坚持以人为本、风险预防、分类管理、协同配合的原则。
- **第五条**：国家鼓励生物科技创新，加强生物安全基础设施和生物科技人才队伍建设。
- **第六十六条**：国家制定生物安全事业发展规划，加强生物安全能力建设。
- **第六十七条**：支持生物安全科技研究，建立多学科、多部门协同创新的联合攻关机制。
- **第六十八条**：统筹布局全国生物安全基础设施建设（生物信息、人类遗传资源保藏、菌（毒）种保藏、动植物遗传资源保藏、高等级病原微生物实验室等国家战略资源平台）。
- **第六十九条**：国务院有关部门根据职责分工，**加强生物基础科学研究人才和生物领域专业技术人才培养，推动生物基础科学学科建设和科学研究**。——这是学科建设最直接的法律依据。
- 适用范围（第二条）涵盖：重大新发突发传染病和动植物疫情、生物技术研究开发利用、病原微生物实验室生物安全、人类遗传资源与生物资源安全、外来物种入侵与生物多样性保护、微生物耐药、生物恐怖袭击与生物武器威胁防御等。

### 教育领域政策
- 教育部等五部门《普通高等教育学科专业设置调整优化改革方案》（2023年3月）：定期编制急需学科专业引导发展清单，完善学位授权审核基本条件。
- 《急需学科专业引导发展清单》首版于2022年编制（含中华早期文明、国际传播、量子科学与技术、高端装备等数十个急需领域），每年动态调整，依规在高等教育系统内部实施。

**小结**：生物安全人才培养已呈"多点布局、层次不齐、分散于多个一级学科之下"的格局——这既是申报一级学科的基础（符合"有一定数量的学位授予单位已开展较长时间人才培养"的设置条件），也是核心问题（缺乏统一学科体系，培养标准不一）。

## 5.3 学界关于设置生物安全学科的论证

1. **学科属性研究**（科学出版社相关著作章节）：生物安全学是新兴学科，兼有自然属性和社会属性；生物学和管理学是其最基本学科基础，数学、计算机科学技术、信息科学技术及预防医学、军事医学、经济学是重要学科基础；在我国现行学位授予专业目录中，生物安全研究属于自主设置的硕士和博士授权点，分属理学（生物学）和农学（植物保护）等领域——即"学科归属困境"。
2. **独立学科建议**：《我国生物安全文化建设的对策研究》等文献建议国家将生物安全设定为独立学科，学科方向涉及生命科学、医药卫生、农林牧渔、食品、生态、环境等多领域。
3. **交叉领域学科建议**：农业科技政策研究文献（《前沿生物技术发展的安全威胁：应对与展望》）建议在高水平大学加快设立交叉领域独立学科、设立研究生学位点，布局生物安全国家重点实验室。
4. **国家安全学框架下的定位**：国家安全学下设"国家安全技术"等二级学科，学界讨论中生物安全被视为国家安全体系的组成要素之一；外交学院已设全球生物安全治理研究中心并参与国家安全学学科评议组活动。

## 5.4 需求侧论据素材（申报论证可用方向）

- **法定机构体系**：《生物安全法》确立的中央国家安全领导机制下的协调机制、各级疾控体系、海关动植物检疫与卫生检疫、农业农村生物安全体系、高等级病原微生物实验室体系，均有法定岗位要求与培训要求（第六十九条第二款：重要岗位从业人员应具备资格并备案、接受岗位培训）。
- **国际治理参与**：《生物安全法》第六条要求参与生物安全国际规则研究与制定——需要既懂生物技术又通晓国际规则的复合型人才（此点现有单一学科难以覆盖）。
- **技术前沿风险**：合成生物学、基因编辑等前沿技术的两用性风险研究已成为国际安全议题，国内相关战略研究力量匮乏（农业科技政策文献明确指出"从事生物安全领域战略研究和技术研究的人员配备还很匮乏，相关学科建设尚未形成体系"）。

## 5.5 申报论证必须直面的反方问题（学科带头人自检清单）

1. 与**国家安全学**（已有一级学科，含国家安全技术二级学科）的关系：是并入其下做方向，还是独立设置？独立设置的不可替代性是什么？
2. 与**公共卫生与预防医学、兽医学、植物保护、生物学、安全科学与工程**的边界：哪些培养内容只有独立的生物安全一级学科才能承载？
3. 学科名称："生物安全" vs "生物安全学" vs "生物安全科学与工程"——需对照命名规范（≤10字、不与现名相同或相似）。
4. 二级学科架构：参照国家安全学4个二级学科的先例，需提出生物安全的二级学科方案（如：生物安全原理与风险评估、生物安全技术与工程、生物安全治理与法治、生物安全战略与国际规则等——此为待论证的工作假设，非官方方案）。
5. 就业出口的规模与稳定性证据：需用人单位（疾控、海关、农业农村、生物医药企业、高等级实验室、军队相关单位）的正式需求文件或调研数据。

> **重要说明**：本章所有现状信息均来自公开渠道；各校最新学位点情况请以教育部每年公布的《学位授予单位（不含军队单位）自主设置二级学科和交叉学科名单》及各校研究生院官网为准。
