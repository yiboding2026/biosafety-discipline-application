# 三、申报途径与重点环节

## 3.1 三条可行路径对比

| 路径 | 制度依据 | 适用情形 | 周期 | 难度 |
|---|---|---|---|---|
| **路径一：目录外二级学科/自设交叉学科备案** | 《授予博士、硕士学位和培养研究生的二级学科自主设置实施细则》（教研厅〔2010〕1号）等 | 任何具有一级学科授权点的单位，立即可以启动 | 每年备案，教育部每年公布名单 | 低门槛，是积累基础的第一步 |
| **路径二：试点交叉学科设置（99码）** | 学位〔2021〕21号 | 仅限**学位授权自主审核单位**（全国三十余所，2024年新增6所） | 校内程序完成后经省级学位委员会报国务院学位委员会批准；试点清单每年公布 | 中门槛，须自主审核资格 |
| **路径三：编入目录成为一级学科** | 《目录管理办法》第十二条；学位〔2021〕21号第十二、十三条 | 试点单位不少于3所、毕业生不少于3届、就业需求旺盛 | 与目录修订同步，每5年一次 | 高门槛，需多校联合与全国布局 |

此外还有一条制度通道：**急需学科专业引导发展清单**（2022年首版，每年动态调整，以目录外学科专业为主），清单内领域在省级申报指南中获优先支持，是推动生物安全进入国家急需视野的重要抓手。

## 3.2 路径一：自设二级学科/交叉学科的操作要点

- 权限：具有博士/硕士学位授权的一级学科下，可自主设置相应层次的目录外二级学科；交叉学科（目录外）设置一般要求涉及3个及以上具博士（或硕士）学位授权的一级学科（各校细则如此规定）。
- 流程（校内）：论证 → 专家评议 → 校学位评定委员会表决 → 校内公示 → 每年12月31日前通过教育部信息平台报国务院学位办备案（论证方案、专家评议意见表、备案表）。
- 已有先例：西南大学在植物保护一级学科下设"生物安全"二级学科硕士点；福建农林大学率先设立"生态安全"二级学科博硕士点；兰州大学设全国首个"生物安全"交叉学科学术学位博士点；中山大学2025/2026年度自主审核获批"生物安全"交叉学科博士点及硕士点。

## 3.3 路径二：试点交叉学科的操作要点

1. 确认本单位是否具有学位授权自主审核资格（无资格单位须联合有条件的单位或走路径一）；
2. 对照学位〔2021〕21号第五条三个基本条件开展自我评估；
3. 严格执行第六条九个校内程序环节（院系申请→部门初审→征求相关学位点意见→编写论证报告→国内外同行专家论证→校内公示→学位评定委员会审议→党委常委会决定→省级学位委员会报国务院学位委员会批准）；
4. 命名规范：不超过10个汉字、不与现有学科同名或近似；建议论证"生物安全"与"生物安全学"等命名；
5. 获批后进入每年公布的试点交叉学科清单，开始积累毕业生规模。

## 3.4 路径三：编入目录的操作要点

- 触发条件（《目录管理办法》第十二条）：试点设置单位**不少于3所**、毕业生**不少于3届**、就业需求旺盛；
- 发起方式：试点单位**联合**其他学位授予单位或相关部门、学术团体、行业组织论证并联合行文（这意味着必须建设跨校联盟）；
- 表决环节：国务院学位办组织专家无记名投票（2/3以上）→ 学科发展战略咨询委员会审议 → 国务院学位委员会批准；
- 时间窗口：目录每5年修订一次（2022年版目录2023年实施），下一轮修订是关键的制度化窗口。

## 3.5 周期性学位授权审核的时间规律（供倒排工期）

以2024年（第十四次）审核为例：

| 时间 | 环节 |
|---|---|
| 2024年1月 | 国务院学位委员会修订印发《博士硕士学位授权审核办法》，启动审核工作 |
| 2024年1—2月 | 各省学位委员会发布本地区通知与申报指南（如江苏省2024年1月29日发文） |
| 2024年上半年 | 学校申请、省级核查公示（≥5个工作日）、省级评议、排序、公示（≥5个工作日）、上报 |
| 2024年年中 | 国务院学位办组织网络评议与复审/核查 |
| 2024年7月31日—8月13日 | 专家核查及评议结果公示（≥10个工作日） |
| 公示后 | 国务院学位委员会审议批准 |

## 3.6 重点环节与风险点（以学科带头人视角）

1. **学科边界论证是第一道关**：必须清晰回答"为什么现有的生物学、植物保护、兽医学、公共卫生与预防医学、安全科学与工程、国家安全学不能涵盖生物安全人才培养"。国家安全学设点时已将部分安全领域纳入"国家安全技术"等二级学科，生物安全与国家安全学的关系是论证绕不开的问题。
2. **社会需求的量化证据**：需拿出法律法规（《生物安全法》）、机构设置（疾控体系改革、海关、农业生物安全体系）、岗位缺口的可核查数据，而非定性描述。
3. **多校联盟**：编入目录要求试点单位不少于3所，应尽早推动3所以上有实力的单位（如已有生物安全交叉学科博士点的兰州大学、中山大学，以及设有相关方向的农林、医学、师范类高校）形成共同论证机制。
4. **不得重复申请规则**：周期性审核中未获批的授权点下一轮不得重复提出（2024年总体要求），申报时机与成熟度评估须审慎。
5. **人员不重复规则**：申请新增授权点与现有授权点的学科带头人、学术骨干不得重复，须提前规划师资归属。
6. **部门同意前置**：涉及国家安全等领域的学科需有关部门同意，行业主管部门支持文件应尽早纳入工作计划。
7. **命名风险**：名称不得与现有学科相同或相似；"生物安全"已是若干二级学科/方向名称，升级为一级学科时的命名与口径须与既有布局协调。
8. **就业与出口设计**：编入目录条件包含就业率与就业质量，培养方案设计阶段就要明确就业面向（疾控、海关、农业农村、应急管理、生物医药企业合规、高等级实验室、军队与国防相关单位等）。
