# 一、学科设置的制度框架与主管部门

## 1.1 制度体系总览

我国研究生层次学科专业设置实行**目录管理制**，核心制度文件如下：

| 文件 | 文号/日期 | 核心内容 |
|---|---|---|
| 《中华人民共和国学位条例》 | 1980年通过、2004年修正 | 学位制度根本依据 |
| 《研究生教育学科专业目录（2022年）》 | 2022年9月发布，2023年起实施 | 14个学科门类、117个一级学科、36个博士专业学位类别、31个硕士专业学位类别 |
| 《研究生教育学科专业目录管理办法》 | 2022年9月随目录印发 | 学科门类、一级学科、专业学位类别的设置条件与程序；目录每5年修订一次 |
| 《交叉学科设置与管理办法（试行）》 | 学位〔2021〕21号，2021年11月17日 | 交叉学科门类下试点交叉学科设置、编入目录、退出机制 |
| 《博士硕士学位授权审核办法》（修订版） | 2024年修订印发（教育部官网2024年4月24日公布） | 新增学位授予单位与学位授权点的审核程序 |
| 《新增博士硕士学位授权审核申请基本条件》 | 2024年发布（教育部官网） | 各类申请单位与授权点的量化基本条件 |
| 急需学科专业引导发展清单 | 首版2022年，每年动态调整 | 以目录外学科专业为主，快速响应国家急需 |

**三级学科专业体系**：学科门类 → 一级学科与专业学位类别 → 二级学科与专业领域。二级学科与专业领域由学位授予单位在一级学科授权权限内**自主设置**（《目录管理办法》第五条）。

## 1.2 主管部门及职责

| 主体 | 职责 |
|---|---|
| **国务院学位委员会** | 学科专业设置与管理的最高决策机构；审议批准学科门类调整、一级学科编入目录、学位授权审核结果 |
| **国务院学位委员会办公室（教育部学位管理与研究生教育司）** | 提出学科门类调整方案；组织试点设置；组织专家评议表决；日常管理 |
| **教育部** | 与国务院学位委员会联合发文；负责招生管理等执行环节 |
| **国务院学位委员会学科发展战略咨询委员会** | 对学科门类调整方案、一级学科编入目录申请进行审议咨询 |
| **国务院学位委员会学科评议组** | 按一级学科设立；参与试点论证征求意见、学位授权点评审、制定学位授予基本要求 |
| **全国专业学位研究生教育指导委员会** | 专业学位类别对应职责 |
| **省级学位委员会** | 制订本地区申报指南；核查申请材料与资格；组织省级评议并排序推荐；试点交叉学科须"经省级学位委员会报国务院学位委员会批准" |
| **学位授权自主审核单位** | 可自主开展试点交叉学科设置（目前全国三十余所，2024年新增6所） |

## 1.3 一级学科设置的基本条件（《目录管理办法》第八条）

新增一级学科采取**先试点后编入目录**方式，设置须体现知识分类并符合四项基本条件：

1. 具有确定的研究对象，已形成相对独立、自成体系的理论、知识基础和研究方法，研究领域和学科内涵与其他一级学科之间有比较清晰的界限；
2. 一般应具有**多个明确的二级学科**；
3. 已得到**学术界的普遍认同**：在构成本学科的领域内，有一定数量的学位授予单位已开展了较长时间的人才培养和科学研究工作，已形成较为系统的课程体系、一定规模的师资队伍及其他培养支撑条件；
4. 社会对本学科培养的人才有**较稳定和一定规模的需求**。

## 1.4 编入目录的程序（《目录管理办法》第十二条）

1. **申请**：试点设置单位不少于3所、毕业生不少于3届、就业需求旺盛的，可由试点设置单位联合其他学位授予单位或相关部门、学术团体、行业组织论证，联合行文向国务院学位委员会办公室提交编入目录申请；
2. **专家评议**：国务院学位委员会办公室组织专家评议，无记名投票，**三分之二及以上**同意方可通过；
3. **审议咨询**：学科发展战略咨询委员会审议；
4. **批准公布**：国务院学位委员会审议批准后编入目录并向社会公布。

## 1.5 交叉学科的特别规定（学位〔2021〕21号）

- **设置主体**：试点交叉学科设置由**学位授权自主审核单位**自主开展；"可通过学科交叉发展的，原则上不应设置为交叉学科"（第四条）。
- **设置条件**（第五条）：① 具有新的、明确的研究对象和需要多学科交叉融合解决的新科学问题，有形成相对独立理论、知识、方法体系的潜力；② 社会对该学科人才有一定规模的迫切需求且趋势稳定；③ 具有结构合理的高水平教师队伍、扎实的相关学科基础和优良的培养条件，基本形成研究生培养体系。
- **校内程序**（第六条，必须包括的环节）：主责院系书面申请 → 管理部门初审 → 征求相关学位授权点意见 → 按提纲编写论证报告 → 国内外同行专家论证 → 校内公示 → 学位评定委员会审议 → 党委常委会研究决定 → 经省级学位委员会报国务院学位委员会批准。
- **命名与编码**：名称一般不超过10个汉字，不得与现有学科名称相同或相似；试点交叉学科代码4位、前两位"99"；编入目录后前两位"14"。
- **编入目录条件**（第十二条）：试点单位达到一定数量且博士毕业生达到一定规模；形成若干稳定成熟的学科方向；师资、课程教材、培养机制、科研支撑、质量保障体系健全；就业率和就业质量高。
- **目录修订周期**：与学科专业目录修订同步，**每5年一次**（第十一条）。2022年版目录自2023年实施，按此推算下一轮修订窗口约为2027年前后。
- **评估**：所有交叉学科学位授权点须参加周期性合格评估；试点交叉学科可不参加第三方评估。

## 1.6 学位授权审核制度（《博士硕士学位授权审核办法》2024年修订版）

- 审核周期：一般每3年开展一轮（2024年为最近一轮完整周期；2024年1月国务院学位委员会修订印发审核办法并启动审核，2024年7月31日公示专家核查及评议结果）。
- 基本程序（六个环节）：学校申请 → 省级学位委员会核查材料并确定申请资格 → 省级组织评议 → 国务院学位委员会复审/核查 → 公示 → 国务院学位委员会正式审批。
- 新增学位授予单位审核基本程序见《审核办法》第十五条：单位申请 → 省级核查并公示不少于5个工作日 → 省级专家评议与会议表决、公示不少于5个工作日后上报 → 国务院学位委员会办公室组织专家评议，获2/3（含）以上同意确定为拟新增单位。
- 2024年总体要求中的重要约束：
  - 新增硕士授权点**以专业学位为主**，一级学科硕士点推荐数不超过推荐硕士点总数的20%；非2022年版目录新设的一级学科硕士点不超过10%；
  - 申请**国家安全学**等一级学科授权点需**经有关部门同意**后方可进入复审或核查环节（生物安全若涉国家安全方向，须提前与相关部门沟通）；
  - 本轮未获批的授权点申请，**下一轮不得重复提出**——意味着每次申报都须确保成熟度；
  - 学科带头人与学术骨干在申请新增授权点与现有授权点之间**不得重复**。
