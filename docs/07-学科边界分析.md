# 七、生物安全与相关一级学科的边界分析

> 本文是申报论证的核心章节底稿。分析维度：研究对象、核心科学问题、方法论体系、法定职责、人才培养出口。所有对相邻学科的描述均以官方学科目录、《研究生教育学科专业简介及其学位基本要求》及权威文献为依据。

## 7.1 生物安全学科的内涵界定（论证起点）

综合《生物安全法》的法定适用范围与学界研究，生物安全的内涵可界定为：

> **一个国家或地区有效应对与生物因素密切相关的各种损害性、破坏性风险和威胁，维护和保障公民生命健康安全、粮食安全、经济安全、生态安全、国防安全乃至总体国家安全的状态和能力。其核心是生物安全能力，即对生物风险的认识、评估、防范和化解能力。**（人民网理论频道《生物安全风险治理的科技哲学思考》，2020-03-23）

《生物安全法》第二条规定的适用范围即学科的法定问题域：

1. 防控重大新发突发传染病、动植物疫情；
2. 生物技术研究、开发与应用安全；
3. 病原微生物实验室生物安全；
4. 人类遗传资源与生物资源安全；
5. 防范外来物种入侵与保护生物多样性；
6. 应对微生物耐药；
7. 防范生物恐怖袭击与防御生物武器威胁；
8. 其他与生物安全相关的活动。

据此，生物安全学科的知识链条可概括为：**风险识别 → 监测预警 → 风险评估 → 防控技术与工程 → 应急处置 → 治理与规则**。这一链条同时具有自然属性（生命科学、医学、农学技术内核）与社会属性（治理、法治、国际规则），是典型的交叉学科。

## 7.2 与相邻一级学科的逐一比较

### 7.2.1 与国家安全学（1402，交叉学科门类）

| 维度 | 国家安全学 | 生物安全 |
|---|---|---|
| 研究对象 | 国家生存与发展的根本性、全局性安全问题及应对 | 生物因子相关的风险与威胁及其防控 |
| 分析单元 | 国家（总体安全观框架下的安全领域集合） | 生物因子—宿主—环境—技术—社会的复合系统 |
| 现有二级学科 | 国家安全思想与理论、国家安全战略、国家安全治理、国家安全技术（范维澄院士披露的4个二级学科架构） | 待论证（见 7.4） |
| 方法论主干 | 战略研究、政策与治理研究、安全工程 | 生命科学技术 + 风险评估 + 防控工程 + 治理规则 |
| 对生物安全的覆盖 | 生物安全是国家安全体系组成要素（《生物安全法》第三条）；国家安全技术方向可涵盖生物安全的**治理与战略层面**；外交学院已设全球生物安全治理研究中心并参与国家安全学学科评议组活动 | — |
| 边界 | **国家安全学不承载生物安全的自然科学与技术内核**：病原学、生物监测检测技术、生物防护装备、实验室生物安全工程、生物风险评估的定量自然科学方法等，不属于国家安全学的知识主干 | **生物安全学科的治理与战略层面与国家安全学交叉**，需通过学科方向设计明确分工 |

**结论**：与国家安全学是"领域安全要素"与"国家安全总论"的关系。若仅将生物安全置于国家安全学之下，其科学技术内核无处安放；若独立设置，则须在学科方案中主动设计与国家安全学的衔接（如治理与战略方向对应、技术方向独立）。

### 7.2.2 与安全科学与工程（0837，工学门类，可授工学、管理学学位）

| 维度 | 安全科学与工程 | 生物安全 |
|---|---|---|
| 研究对象 | 人类生存与发展中的事故、灾害等安全问题的一般规律（源于矿山、工业安全传统） | 生物因子相关风险（具有生命系统特性） |
| 现有二级学科 | 安全科学与系统工程、安全技术、智能安全、应急与安全管理、职业安全健康（《研究生教育一级学科和专业学位类别下设二级学科目录》） | 待论证 |
| 方法论 | 安全系统工程、风险评价、应急管理的一般理论方法 | 需以生命科学实验与监测数据为基础的风险识别评估方法 |
| 关键区别 | **一般工程安全对象是被动的、物理化学性的危险源**；其风险参数相对稳定 | **生物因子具有自复制、变异、传播、潜伏、跨物种溢出等生命系统特性**，风险动态演化，检测评估依赖生物学实验体系（如BSL分级实验室），不是一般安全工程方法所能覆盖 |
| 交叉点 | 风险管理与应急管理的通用方法论可借用 | 生物安全的事件应急处置方向与安全科学与工程方法论互通 |

**结论**：安全科学与工程提供方法论工具，但无法替代生物安全的生命科学内核。正如核安全未并入安全科学与工程而是依托核科学与技术（0827）发展，生物因子的特殊性同样需要独立的学科承载。

### 7.2.3 与公共卫生与预防医学（1004，医学门类）

| 维度 | 公共卫生与预防医学 | 生物安全 |
|---|---|---|
| 研究对象 | 人群健康与疾病预防控制 | 人、动物、植物、环境全谱系的生物风险（One Health 之上再加技术安全与国家安全维度） |
| 覆盖范围 | 重大传染病防控是其核心之一 | 传染病仅是《生物安全法》八类适用对象之一；动植物疫情、外来物种入侵、两用生物技术治理、生物恐怖防御、人类遗传资源安全等均超出公共卫生范畴 |
| 价值取向 | 健康导向 | 安全导向（统筹发展和安全） |
| 现实关系 | 中山大学生物安全学院即由公共卫生学院（深圳）更名而来，说明两学科师资与平台高度共享 | 但学院更名本身也印证了"公共卫生学科框架装不下生物安全"的制度判断 |

**结论**：公共卫生与预防医学是生物安全最重要的相邻学科与人才来源，但生物安全的问题域显著大于人群健康。

### 7.2.4 与兽医学（0906）、植物保护（0904，农学门类）

- 兽医学、植物保护分别从动物健康、植物保护的生产视角覆盖生物安全的局部对象（动物疫情、检疫性有害生物、转基因生物风险评估等）；
- 西南大学在植物保护下设"生物安全"二级学科、福建农林大学设"生态安全"二级学科，证明农学门类是当前生物安全研究生培养的主要载体之一；
- 边界：农学学科以**农业生产目标**为导向，不覆盖人类传染病、实验室生物安全、两用技术治理、生物恐怖防御等对象；且其"安全"研究服务于产量与品质目标，而非国家安全目标。

### 7.2.5 与生物学（0710）、生物工程（0836）、生物医学工程（0831）

- 这三个学科是"**发展侧**"学科：认识生命规律（生物学）、利用生物技术进行工程化生产（生物工程）、医学仪器与工程（生物医学工程）；
- 生物安全是"**安全侧**"学科：研究上述学科产出的技术与对象带来的风险及其防控；
- 边界清晰：正如核科学与技术（发展）与核安全、食品科学与工程（发展）与食品安全治理的关系，**发展的学科不能替代对发展风险的学科化研究**；
- 这三者是生物安全最主要的学科基础与师资来源。

### 7.2.6 参照系：网络空间安全（0839）的设立逻辑

网络空间安全于2015年前后设立为一级学科，其论证逻辑与生物安全高度同构：对象具有特殊技术内核（网络系统 vs 生物因子）、已有相关学科（计算机科学与技术 vs 生物学/公共卫生）无法完整覆盖、国家安全立法与人才需求驱动。这一先例说明"**领域安全类一级学科**"在我国学科体系中已有制度先例。

## 7.3 边界分析的综合结论

1. **没有任何一个现有一级学科覆盖生物安全知识全链条**。生物学—公共卫生—兽医学—植物保护—安全科学与工程—国家安全学各自覆盖链条的一段或一个视角；现状是"多段拼凑、标准不一"。
2. **生物安全学科的不可替代性在于三点**：① 研究对象的生命科学内核（活的、可变异、可传播的生物因子）；② 《生物安全法》确立的独立监管体系与岗位资格制度（第六十九条第二款规定的岗位资格与备案培训制度）；③ 横跨"人—动物—植物—环境—技术—治理"的全谱系问题域。
3. **诚实的风险提示**：反对者最有力的论点是"可通过国家安全学 + 公共卫生与预防医学 + 农学学科的交叉协作覆盖"（学位〔2021〕21号第四条"可通过学科交叉发展的，原则上不应设置为交叉学科"）。回应此点的关键证据是：现有分散布局十年来未能形成统一培养体系与稳定人才供给（详见 05 号文档引用的"人员配备匮乏、学科建设尚未形成体系"的评估），且2026年5月中山大学将学院整体更名为生物安全学院，反映一线高校用建制投票判断"交叉协作不够"。

## 7.4 二级学科设置建议方案（工作假设，供论证讨论）

> 以下为论证用工作假设，非官方方案。设计逻辑参照国家安全学"思想理论—战略—治理—技术"4个二级学科的先例，覆盖生物安全知识全链条。

| 建议二级学科 | 覆盖的知识链条 | 主要学科基础 |
|---|---|---|
| 生物安全原理与风险评估 | 风险识别、监测预警、风险定量评估 | 生物学、数学、信息科学、流行病与统计方法 |
| 生物安全技术与工程 | 防控技术、检测监测技术、实验室生物安全工程、防护装备 | 生物工程、生物医学工程、兽医学、病原微生物学 |
| 生物安全治理与法治 | 监管体系、法律法规、伦理、应急管理 | 公共管理、法学、安全科学与工程 |
| 生物安全战略与国际规则 | 国家安全战略、国际军控与防扩散、《禁止生物武器公约》与国际规则、全球生物安全治理 | 国际关系、国家安全学、情报与政策研究 |

备选方案：按对象域设置（人兽共患与传染病安全、农业生物安全、实验室与生物技术安全、生物安全治理）。两种方案的取舍应在专家论证阶段重点讨论。

## 7.5 学科门类归属建议

- 首选：**交叉学科门类（14）**，参照国家安全学模式，可授理学、工学、农学、医学学位；
- 理由：学位〔2020〕30号将集成电路、国家安全学两个"研究对象涉及较多现有一级学科、多学科综合交叉特点突出"的学科置于交叉学科门类，生物安全完全符合同一逻辑；
- 试点阶段代码：99XX（按学位〔2021〕21号第九条），编入目录后14XX顺排。
