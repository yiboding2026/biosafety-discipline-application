# 四、国内一级学科设置成功案例复盘

## 4.1 案例一：国家安全学（1402）——与生物安全最接近的样板

### 时间线

| 时间 | 事件 | 来源性质 |
|---|---|---|
| 2015年前后 | 部分高校在相关学科下探索国家安全研究方向/二级学科 | 学界文献 |
| 2018—2019年 | 西南政法大学2018年5月在全国普通高校中首个成立国家安全学院；吉林大学2019年6月成立国家发展与安全研究院；北京师范大学2019年4月成立国家安全与发展战略研究院 | 各校官网 |
| 2019年起 | 教育部确定首批"国家安全人才培养试点单位"（吉林大学、北京师范大学、西南政法大学等），2020年9月开始招收博士、硕士研究生 | 各校官网 |
| 2020年12月30日 | 国务院学位委员会、教育部印发《关于设置"交叉学科"门类、"集成电路科学与工程"和"国家安全学"一级学科的通知》（学位〔2020〕30号） | 官方文件 |
| 2021年5月 | 教育部启动国家安全学一级学科博士、硕士学位授权点增列工作 | 学界文献 |
| 2021年10月 | 国务院学位委员会下发《关于同意增列国家安全学一级学科学位授权点的通知》，首批14家单位：北京大学、清华大学、北京师范大学、吉林大学、复旦大学、南京大学、国防大学、中国人民公安大学、西南政法大学、中国现代国际关系研究院10家博士点建设单位；国际关系学院、中共中央党校（国家行政学院）、外交学院、陕西师范大学4家硕士点建设单位 | 官方文件+媒体报道 |
| 2021年11月17日 | 《交叉学科设置与管理办法（试行）》（学位〔2021〕21号）印发 | 官方文件 |
| 2023年10月 | 吉林大学、南京大学、西南政法大学获批首批国家安全学博士后科研流动站 | 公开报道 |
| 截至2024年12月 | 国家安全学一级学科博士点达21个、硕士点13个（中国现代国际关系研究院文献）；另有文献称截至2025年底为21个博士点、17个硕士点 | 学界文献 |

### 可复制的经验

1. **国家战略立法先行**：《国家安全法》（2015年）明确要求将国家安全教育纳入国民教育体系；教育部《关于加强大中小学国家安全教育的实施意见》明确提出设立国家安全学一级学科。——对应生物安全：《生物安全法》2021年施行，立法基础已具备。
2. **专家论证组织化**：范维澄院士担任国家安全学学科设置论证专家组组长、后任学科评议组召集人；清华大学申世飞任论证工作组组长。——权威学术带头人牵头论证是关键变量。
3. **先建机构、先试点培养**：首批获批单位全部在设一级学科之前2—3年成立了专门研究院/学院并承担了教育部人才培养试点。
4. **二级学科架构快速定型**：国家安全学下设4个二级学科（国家安全思想与理论、国家安全战略、国家安全治理、国家安全技术），并允许各单位横向发展特色方向（如吉林大学设粮食安全、东北亚安全方向）。
5. **特殊审批通道**：2024年授权审核总体要求规定，申请国家安全学等一级学科授权点需经有关部门同意——体现了安全类学科的特殊管理口径。

## 4.2 案例二：集成电路科学与工程（1401）

| 时间 | 事件 |
|---|---|
| 2018年 | 复旦大学着手谋划集成电路科学与工程一级学科建设 |
| 2020年 | 复旦大学率先开展该一级学科试点并启动博士招生（早于国家正式设置） |
| 2020年12月30日 | 与国家安全学同期，经学位〔2020〕30号设置为交叉学科门类一级学科 |
| 2021年10月 | 国务院学位委员会批准首批19所高校的集成电路科学与工程一级学科博士、硕士学位授权点（杭州电子科技大学为其中唯一非"双一流"博士点高校） |
| 2022年 | 复旦大学成为第二轮"双一流"名单中唯一凭集成电路科学与工程学科登榜的高校 |

**经验**：服务"卡脖子"国家重大需求、产业人才缺口数据充分、龙头高校先行试点形成示范。

## 4.3 案例三：2022年版目录新增的其他一级学科

《研究生教育学科专业目录（2022年）》（2022年6月国务院学位委员会第37次会议审议通过，2022年9月印发）一次性新设了一批一级学科/交叉学科，体现了"服务国家治理现代化"与"科技前沿"两类逻辑：

- **治理类**：中共党史党建学、纪检监察学、区域国别学；
- **科技类**：智能科学与技术、遥感科学与技术、纳米科学与工程、水土保持与荒漠化防治学、法医学；
- 交叉学科门类新增设计学等，门类内一级学科达7个（1401—1407）+2个专业学位类别（1451文物、1452密码）。

**经验**：新版目录修订（每5年一次）是新一级学科进入目录的制度化主渠道；生物安全若申报，最可能的门类归属即交叉学科门类。

## 4.4 案例四：公共卫生相关——疫情后"超常规布局"的启示

2020年新冠疫情后，教育部"超常规布局集成电路、公共卫生等人才培养专项"（2021年）；2022年版目录将公共卫生专业学位调整到博士层次。说明**重大突发公共事件会直接改变学科设置的国家优先级**——生物安全与公共卫生高度关联，这是论证国家急需性的重要事实背景。

## 4.5 横向对比：成功案例的共同要件

| 要件 | 国家安全学 | 集成电路 | 生物安全现状评估 |
|---|---|---|---|
| 国家法律/战略文件 | 《国家安全法》2015 | 国家集成电路产业政策 | ✅《生物安全法》2021 |
| 权威院士/专家牵头 | 范维澄等 | 行业院士群体 | 已有院士推动（如谢联辉推动生态安全二级学科与生物安全本科专业），但尚无全国统一的论证专家组 |
| 先行试点培养 | 教育部首批试点单位2019年起 | 复旦2020年试点 | 兰州大学、中山大学已有交叉学科博士点 |
| 多校机构布局 | 2018—2019年多校成立学院 | 多校集成电路学院 | 兰州大学动物医学与生物安全学院（2021）、多校相关方向 |
| 人才缺口数据 | 国家安全人才需求 | 产业缺口量化清晰 | ⚠️ 需系统量化 |
| 与现有学科边界 | 明确4个二级学科 | 从电子科学与技术分离 | ⚠️ 与国家安全学、生物学、公共卫生等边界需深入论证 |
