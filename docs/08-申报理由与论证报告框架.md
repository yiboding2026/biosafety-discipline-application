# 八、申报理由与论证报告框架

> 本文分两部分：A. 申报理由（必要性论证主线）；B. 按《交叉学科设置与管理办法（试行）》（学位〔2021〕21号）要求设计的论证报告框架。框架为工作底稿，具体数据需在申报单位层面核实填充。

## A. 申报理由

### 理由一：设立生物安全一级学科是落实国家法律与党中央决策部署的直接要求

- 2020年2月，中央全面深化改革委员会第十二次会议明确"把生物安全纳入国家安全体系，系统规划国家生物安全风险防控和治理体系建设"（人民网理论频道文献转述）。
- 《中华人民共和国生物安全法》（2021年4月15日施行）第三条确立"生物安全是国家安全的重要组成部分"；**第六十九条明确规定"国务院有关部门根据职责分工，加强生物基础科学研究人才和生物领域专业技术人才培养，推动生物基础科学学科建设和科学研究"**——这是以法律形式提出的学科建设要求。
- 对照先例：《国家安全法》2015年要求将国家安全教育纳入国民教育体系 → 2020年国家即设立国家安全学一级学科。生物安全已完成同等的立法步骤，学科设置具备同构的政策逻辑。

### 理由二：生物安全风险形势要求成建制的专门人才供给

- 法定问题域覆盖八类对象（传染病、动植物疫情、生物技术两用性、实验室生物安全、人类遗传资源、外来物种入侵、微生物耐药、生物恐怖与生物武器威胁），每一类都有对应的法定监管职责和岗位资格要求（《生物安全法》第六十九条第二款规定重要岗位从业人员须具备资格、备案并接受岗位培训）。
- 前沿生物技术的两用性风险（合成生物学、基因编辑）已成为国际安全议题，而国内"从事生物安全领域战略研究和技术研究的人员配备还很匮乏，相关学科建设尚未形成体系"（农业科技政策研究文献，《前沿生物技术发展的安全威胁：应对与展望》）。

### 理由三：现有学科布局无法承担系统培养任务，碎片化格局已形成明确证据

- 生物安全研究生培养目前分散于植物保护（西南大学"生物安全"二级学科）、兽医学、公共卫生与预防医学、生物学等多个一级学科之下，培养标准、课程体系、出口方向互不统一；
- 科学出版社相关研究明确指出生物安全面临"学科归属困境"：不同学科背景人员对生物安全的认识差异巨大，理学、农学、公共安全、军事学、情报学各有主张；
- 一线高校已用建制行动作出判断：兰州大学2021年成立动物医学与生物安全学院并建全国首个生物安全交叉学科博士点；中山大学2026年5月将公共卫生学院（深圳）整体更名为生物安全学院——说明**既有学科框架承载不了生物安全人才培养**，倒逼高校以撤并重组方式突围。

### 理由四：学科自身已具备设置基本条件

对照《研究生教育学科专业目录管理办法》第八条四项基本条件：

| 条件 | 论证要点 |
|---|---|
| 确定的研究对象、相对独立的理论知识体系、与其他一级学科界限清晰 | 研究对象＝生物因子相关风险；知识链条（识别—评估—防控—治理）完整；与6个相邻学科的边界已可系统论证（见 07 号文档） |
| 一般应具有多个明确的二级学科 | 可提出4个二级学科方案（原理与风险评估、技术与工程、治理与法治、战略与国际规则） |
| 学术界普遍认同、一定数量单位已长期开展培养研究 | 兰州大学、中山大学已设交叉学科博士点；多所高校设相关二级学科/方向；中山大学设全国首个生物安全学院；已有全国入侵生物学大会等学术共同体活动（2026年第七届） |
| 社会有稳定和一定规模的需求 | 法定监管体系（疾控、海关、农业农村、高等级实验室）+ 法定岗位资格制度 + 生物医药产业合规需求 |

### 理由五：服务国际规则参与和全球生物安全治理

《生物安全法》第六条要求参与生物安全国际规则的研究与制定、推动完善全球生物安全治理。此类人才需要"生物技术 + 国际规则"的复合知识结构（农业科技政策文献明确呼吁），现有单一学科均无法成建制培养，只有独立学科才能稳定供给。

### 申报路径的现实选择（与理由配套）

1. 近期（1年内）：具备学位授权自主审核资格的单位按学位〔2021〕21号启动**试点交叉学科**（99码）校内论证；不具备资格的单位先设目录外二级学科/交叉学科并备案，扩大布局基数；
2. 中期（2—3年）：推动≥3所单位形成试点布局，积累毕业生；争取将生物安全纳入下一版《急需学科专业引导发展清单》；
3. 远期（2027年前后目录修订窗口）：联合多校、学术团体、行业主管部门，按《目录管理办法》第十二条申请**编入目录**成为交叉学科门类一级学科。

## B. 试点交叉学科论证报告框架（按学位〔2021〕21号）

### 第一部分 学科内涵与设置必要性

1.1 学科名称、代码申请与学位授予门类建议
- 名称建议：生物安全（或生物安全学，需对照命名规范查重）；代码：试点99XX；学位授予：理学/工学/农学/医学
1.2 学科内涵界定（引用 07 号文档 7.1 的界定）
1.3 设置必要性（引用本文 A 部分五条理由，逐条附证据）
1.4 设置可行性（法律政策窗口、前期布局、平台条件）

### 第二部分 研究对象、理论体系与学科边界

2.1 研究对象与核心科学问题
- 需要多学科交叉融合解决的新科学问题（对照21号文第五条第一项）：如新发传染病跨物种溢出机制与预警、生物风险的定量评估方法、两用生物技术的风险治理机制等
2.2 相对独立的理论、知识和方法体系的发展潜力
2.3 与相关一级学科的关系（引用 07 号文档全部六个比较，重点展开与国家安全学、公共卫生与预防医学的关系）
2.4 对"可通过学科交叉发展则不设交叉学科"条款的回应论证

### 第三部分 社会需求分析

3.1 法定需求：《生物安全法》监管体系、岗位资格制度、部门职责清单
3.2 机构需求：疾控体系、海关、农业农村体系、高等级病原微生物实验室（含国家批准建设的华南高等级生物安全实验室等）、军队国防相关单位
3.3 产业需求：生物医药企业生物安全合规、实验室服务产业
3.4 需求的稳定性与规模论证（须以正式调研数据和主管部门文件支撑——**此部分是当前最大短板，须立项调研**）

### 第四部分 二级学科设置方案

4.1 方案A（按知识链条）：原理与风险评估／技术与工程／治理与法治／战略与国际规则
4.2 方案B（按对象域）：人兽共患与传染病安全／农业生物安全／实验室与生物技术安全／生物安全治理
4.3 两方案比较与推荐意见（须经专家论证确定）

### 第五部分 人才培养方案要点

5.1 培养目标与规格（博士/硕士分层）
5.2 生源分析：生物学、医学、农学、工学、管理学背景考生的知识衔接设计
5.3 课程体系：核心课程模块建议（生物安全原理、生物风险评估方法、病原微生物学与实验室安全、生物安全法律法规与伦理、生物安全战略与国际规则、应急处置演练）
5.4 实践环节：高等级实验室实训、疾控/海关实习、应急演练
5.5 学位授予基本要求草案

### 第六部分 师资队伍与支撑条件

6.1 教师队伍现状与建设规划（结构、规模、双师型、跨学科聘任机制）
6.2 相关学科基础（须涉及3个及以上具博士学位授权的一级学科——列明本单位依托学科清单）
6.3 平台条件：高等级实验室、国家重点实验室、保藏机构、应急演练平台
6.4 管理制度：交叉学科的人员、成果、绩效考核评价机制（21号文第二十二条要求）

### 第七部分 国内外比较与发展规划

7.1 国际生物安全学科与人才培养概况（美国生物防御、欧洲One Health等，须另行补充调研）
7.2 国内已有布局与本单位特色定位（避免同质化，对照21号文及目录管理办法"避免同质化发展"要求）
7.3 五年建设规划与质量保障机制（含参加周期性合格评估安排）

### 附录（程序性材料清单）

- 院系书面申请、管理部门初审意见、相关学位授权点意见、国内外同行专家论证意见、校内公示证明、校学位评定委员会决议、党委常委会决定、经省级学位委员会报国务院学位委员会的文件

> **使用提示**：正式撰写论证报告时，第三部分（需求数据）与第六部分（本单位师资平台）必须使用可核查的一手数据；论证报告如获授权，将作为学位授权点核验的参考材料，填报口径须前后一致。
